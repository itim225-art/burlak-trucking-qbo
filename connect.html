Connect or Reconnect to QuickBooks Online

Burlak Trucking QuickBooks Integration · Private internal application

This application is a private internal tool operated by Burlak Trucking Inc. It is not a public product and has no public sign-up. Access is limited to the owners of the company.

How authorization works

  1. An authorized company owner starts the connection from the local application.
  2. Intuit's OAuth 2.0 consent screen opens in a browser.
  3. The owner signs in with the Intuit account that owns the QuickBooks Online company and grants the accounting scope.
  4. Intuit returns an authorization token, which is stored locally on company-controlled hardware.

Reconnecting

Authorization may need to be renewed if it has been revoked, or if the connection has gone unused past Intuit's refresh-token expiry window. Reconnecting repeats the same steps above. No QuickBooks or Intuit password is ever seen or stored by this application.
